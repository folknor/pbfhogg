# Deviations from osmium

Intentional behavioral differences between pbfhogg's commands and
osmium-tool's: for each one, what osmium does, what pbfhogg does, where their
outputs differ and why. These are deliberate design choices, not bugs.

They are kept in one place, in the repository:
[DEVIATIONS.md](https://github.com/folknor/pbfhogg/blob/main/DEVIATIONS.md).
This site does not carry a copy, so there is no second version to fall out of
date. [Osmium Parity](./osmium-parity.md) maps each osmium command to its
pbfhogg counterpart.

Parser and encoder edge cases are in [Correctness](../guide/correctness.md).

Old section fragments on this pointer page are not forwarded, and site
search does not index the linked content. Keeping headings or content here
would create a second copy that could drift; use the repository sections.
