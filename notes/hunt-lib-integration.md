Inspected commit `c95f9998` on `bygg`. This is a read-only report. I did not run builds, tests or benchmarks. Costs below are derived from source, not measured timings. Findings are unranked.

1. **The shared sortedness assertion cannot detect type interleaving, and uses the wrong order for negative IDs.** [assert_sorted_file](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:1446) reads through a helper that separates nodes, ways and relations into different vectors. A file containing way 1 followed by node 1 therefore passes its type-order check, because that check never actually happens. Its raw `i64 >=` comparisons also reject canonical OSM order such as `-1, -2`, which [the check tests explicitly recognize](/home/folk/Programs/pbfhogg/crates/lib/tests/check.rs:72). This weakens apply-changes and renumber assertions today. Check `(kind, canonical ID key)` directly while traversing the file. Enforce the helper's contract with deliberately interleaved, inverted and correctly ordered mixed-sign fixtures.

2. **The shared equivalence oracle discards metadata that production now treats as meaningful.** [meta_from_info](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:1287) drops every plain metadata field when `version()` is absent. Both metadata normalizers truncate milliseconds to seconds and collapse absent fields into zero or empty values. Plain and dense metadata also follow different presence rules. Production's [MetaClaims](/home/folk/Programs/pbfhogg/crates/lib/src/read/claims.rs:1) now preserves individual claims. Consequently, equivalence tests can miss lost unversioned metadata or subsecond timestamp changes. Replace this broad normalization with an explicit, independently decoded comparison model that preserves field presence and precision; offer narrower comparisons where a command intentionally changes them. Enforce it with counterexamples differing in exactly one field or one millisecond.

3. **The same oracle hides decoding errors, duplicate tags and unknown member types.** [The normalizers](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:1329) collect tags into `BTreeMap`, replacing duplicate keys, turn failed user and role lookups into empty strings, and reduce every unknown member type to `"unknown"`. [The coordinate reader](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:1031) also swallows role errors. A corrupted empty role can compare equal to a valid empty role; distinct unknown types can compare equal. Preserve tag multiplicity, retain numeric unknown types, and fail on unexpected decoding errors. Negative tests for the comparison helpers can enforce these distinctions; a scoped lint can forbid error-to-empty conversions in fixture readers.

4. **An empty output can satisfy the normalized-content assertions without being a valid PBF.** [read_normalized](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:1405) uses `BlobReader`, ignores headers, and returns empty sections for an empty byte stream. For example, [empty_pbf_survives_sort](/home/folk/Programs/pbfhogg/crates/lib/tests/edge_cases.rs:76) would accept a zero-byte output because it only checks those empty sections. Make successful-output readers require a valid leading header and complete framing before comparing elements. Enforce this with empty-file, missing-header and malformed-tail control tests.

5. **One metadata assertion is literally absent, behind an obsolete explanation.** [test_meta_roundtrips_through_writer](/home/folk/Programs/pbfhogg/crates/lib/tests/fixture_helpers.rs:153) says the metadata-less node should remain metadata-less, then finishes with `let _ = n2.meta.as_ref()`. That cannot fail for any metadata value. Its explanation about fabricated zero metadata also contradicts [roundtrip_mixed_metadata](/home/folk/Programs/pbfhogg/crates/lib/tests/roundtrip.rs:1141), which asserts the newer separate-group behavior. Assert `None`, preferably against the decoded node directly. A regression test enforces the behavior; a narrow lint can reject discarded expressions in assertion helpers, although it cannot generally determine assertion adequacy.

6. **The all-blobs index guard passes when there are no readable blobs.** [assert_every_data_blob_indexed](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:912) asks whether the successfully located prefix contains an unindexed data blob. [locate_blobs](/home/folk/Programs/pbfhogg/crates/lib/tests/common/adversarial.rs:70) deliberately stops at malformed framing. Empty input, malformed input before the first complete frame, and malformed suffixes can therefore pass this guard. The tagdata counting helper already checks complete consumption. Introduce separate strict and prefix-tolerant framing APIs, with strict parsing returning the consumed extent and frame kinds. Test the strict index guard against malformed framing and require data presence when its caller expects data.

7. **Several fixture descriptions are false today, and their smoke tests do not fully hold the descriptions.** [write_bad_indexdata_pbf](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:395) promises 30 zero bytes but `resize(30, 0)` truncates the existing 42-byte index, retaining its version and prefix. It still creates malformed input, but tests are exercising a different malformation. [The multiblock example](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:354) says seven data blobs where [its smoke test correctly expects six](/home/folk/Programs/pbfhogg/crates/lib/tests/fixture_helpers.rs:26). [The base/changed contract test](/home/folk/Programs/pbfhogg/crates/lib/tests/fixture_helpers.rs:199) checks node and way IDs, but not unchanged relations or preservation of other fields despite claiming exactly the documented edits. Assert the exact malformed bytes and compare complete fixture contents against explicit edits. Executable examples can enforce counts; arbitrary prose cannot be mechanically guaranteed.

8. **`test_host()` does not provide the same execution machine on every host.** [fixed_resources](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:1696) reports four cores, but [test_host](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:1711) selects `Executor::Ambient`. Off a Rayon worker that reaches the global pool, whose width depends on the actual host and Rayon configuration. Commands using executor width can therefore behave differently despite the fixed resource provider, and concurrent tests contend on that pool. Give ordinary tests an explicitly sized executor; reserve ambient execution for tests whose subject is ambient execution. A fixture-host type and lint against ambient executors outside named tests can hold this mechanically.

9. **The shared host changes process policy and then uses unreserved ambient descriptor estimates.** [test_host](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:1712) raises `RLIMIT_NOFILE` once, discards the result, and supplies `NoProcessActions`. That provider still probes the real process's open descriptors. Its allowance changes with sibling tests, while simultaneous descriptor-heavy tests can each receive overlapping estimates. [The production contract explicitly warns about this](/home/folk/Programs/pbfhogg/crates/lib/src/host.rs:1650). A high hard limit masks the coupling; a constrained host can refuse work or encounter descriptor exhaustion. Move limit setup to an explicit harness boundary, report its outcome, and coordinate descriptor-heavy tests through a reserving budget or isolated execution. Enforce provider selection structurally and keep actual limit-mutation scenarios in their own target.

10. **Publication concurrency tests pay real time to infer whether another thread ran.** [The ordinal test](/home/folk/Programs/pbfhogg/crates/lib/tests/publication.rs:99) sleeps 50 ms before asserting that the second publisher is unfinished. An unscheduled second thread satisfies that assertion without reaching the lock. [PublishOrder](/home/folk/Programs/pbfhogg/crates/lib/tests/host_contract.rs:692) deliberately waits 500 ms on the correct serialized path, and its hooks add two 20 ms sleeps. Together these introduce about 590 ms of aggregate test time per sweep, approximately 2.95 seconds across the five default sweeps. Add an observable publication-lock attempt and synchronize on it, then release the first publisher. Enforce this through a reusable contention fixture and a lint against sleeps in these tests.

11. **The parked-reader fixture can deadlock while unwinding from the assertion it is meant to diagnose.** [ParkingRead](/home/folk/Programs/pbfhogg/crates/lib/tests/capabilities.rs:47) blocks on an unbounded receive. In [its test](/home/folk/Programs/pbfhogg/crates/lib/tests/capabilities.rs:70), the block iterator is created after the release sender. If a capability assertion fails before release, unwinding drops the iterator first; its pipeline join waits for the reader, while the sender remains alive farther down the stack. A useful assertion failure becomes a watchdog kill. Bundle the iterator and release mechanism into a guard whose destructor releases before joining. Test that cleanup by deliberately unwinding while the reader is parked.

12. **Several hang tests detach the work they time out.** [The read-path tests](/home/folk/Programs/pbfhogg/crates/lib/tests/read_paths.rs:459) and [renumber_within_deadline](/home/folk/Programs/pbfhogg/crates/lib/tests/renumber_external.rs:1214) discard their thread handles and wait on a result channel. On timeout, the worker can remain alive with files, pipeline threads and executor work while other tests continue in the shared binary. The fixture directory may be removed underneath it. A truly hung thread cannot be safely reclaimed in-process: run these hang regressions in a killable test process, or provide cancellation that is guaranteed to release every fixture block and join. Enforce worker ownership through a common harness and forbid discarded spawn handles outside explicitly isolated targets.

13. **FIFO capture repeats polling and has incomplete lifetime ownership.** [Capture](/home/folk/Programs/pbfhogg/crates/lib/tests/seal.rs:24) and [the host-contract capture](/home/folk/Programs/pbfhogg/crates/lib/tests/host_contract.rs:475) poll nonblocking reads with 1 ms sleeps. They duplicate setup and drainage logic. `Capture` joins only through `finish`; an earlier panic drops the join handle and lets cleanup finish asynchronously. Both sites also require the repository path to be UTF-8 through `to_str()`, whereas [make_fifo](/home/folk/Programs/pbfhogg/crates/lib/tests/common/mod.rs:78) already accepts native path bytes. Consolidate capture into an owning fixture with event-driven reads, explicit shutdown and joined cleanup. Test its unwind path and non-UTF-8 paths; ban local FIFO-drain implementations afterward.

16. **The standalone descriptor test still assumes more about Linux than its subject requires.** [process_nofile](/home/folk/Programs/pbfhogg/crates/lib/tests/process_nofile.rs:85) correctly owns its process, but skips the whole combined test below a hard limit of 1024, requires procfs counting to succeed, and assumes every descriptor number below its highest held descriptor is occupied.
